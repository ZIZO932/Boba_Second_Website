# Boba, second try

My second Boba website, made at another Hack Club Giza workshop. This time I tried building a few pages instead of keeping everything on one.

It's still a simple HTML and CSS project, with a home page, an about page, a menu, and a custom 404 page.

## Open it

Download the repo and open `index.html` in your browser. The navigation links take you to the other pages. No build step or packages needed.

## Files

- [index.html](index.html) — home page
- [about.html](about.html) — about page
- [menu.html](menu.html) — menu
- [404.html](404.html) — custom error page
- [style.css](style.css) — shared styling

Here's [my first version](https://github.com/ZIZO932/Boba_First_Website) if you want to compare them.
